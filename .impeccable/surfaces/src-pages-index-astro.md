# Surface brief: homepage + keyword tool pages

Scope: `/` and every `/pinterest-*` tool landing page (they share one hero and form). Mode: Persuade (tool landing), with the paste-and-save task working in the first viewport.

Audience/job: phone visitor from Google with one public Pinterest link; wants the real file saved, then leaves. Proof is the working tool itself; no testimonials or counts exist.
Constraints: paste box above the fold everywhere; CLS-safe ad slots; SEO copy, JSON-LD and headings keep their content.
Memorable moment: pasting a link stamps the ticket with its type and the real pin ID; Download tears the stub off.
Unresolved: no ad network yet (slots reserved, invisible until configured).

## Direction contract

THESIS: A link is a claim ticket and the file is what you collect. Refuses the category's centred headline over a rounded input with a 3-step icon row and card grid.

OWN-WORLD: Perforated ticket-roll stock. Committed ticket-red (#C8281A family) field owns the hero; white ticket paper on it; each tool has its own stock (video tangerine, image canary, GIF lilac, board mint, profile sky, PFP pink). Condensed gothic display (Big Shoulders) for headlines and serial numerals; system sans body. Small 4px corners, punched notches, dashed perforations; no drop shadows or gradients — depth only by flat paper overlap (raise from Łowicz papercut). One stock = one URL type, cross-checked against the paste (raise from six-pack). Small honest counters only: pin ID, format, size (raise from minihompy).

STORY: Visitor sees the ticket, pastes, sees the stamp confirm the link type (or redirect to the right tool), downloads, leaves; on scroll learns other tools as a rack of ticket stocks.

FIRST VIEWPORT: Full-width red field. Mobile: H1 in condensed gothic, two lines, left-aligned; below it the white ticket, full width minus 16px: header strip "ADMIT ONE PUBLIC LINK" + stock label, input row, Download button as the tear-off stub across a dashed perforation, notches at the perforation ends. Stub is always the top layer (raise from cel dawn). Desktop: H1 left column, ticket right at 560px.

FORM: Coat-check / claim-ticket roll, position 7 of 7 on the ordered list. seed: none (unavailable). Signature interaction: perforation tear on download, stamp on link detection; reduced motion fades.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
