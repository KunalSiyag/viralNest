Locale **id** · hreflang **`id`** · market: Indonesia (gl=id) · researched 14–15 Oct 2026 · 275 Google autocomplete seeds plus competitor and Pinterest help-center checks.

## Summary

- **15 of 19 pages localize, 4 skip** (pinterest-profile-downloader, pinterest-carousel-downloader, pinterest-4k-downloader, pinterest-seo-title-generator).
- **Search vocabulary:** Indonesians search with the English loan verb **download** ('download video pinterest', 'cara download video pinterest di hp'). 'unduh' has a smaller tail of its own. The strongest modifiers are **tanpa watermark**, **ke galeri**, **tanpa aplikasi**, **di hp**, **di laptop**, **HD** and **tanpa login**.
- **Photos and boards:** 'foto' outranks 'gambar' for photos. People search **board**, while the Pinterest app says **papan**: use 'board' in titles and slugs and 'papan' in the steps.
- **Profile pictures:** they are **PP** or **foto profil**, and that page faces almost no Indonesian competition. The profile-to-ZIP intent has no Indonesian demand.
- **Competitors:** they are machine-translated, use formal 'Anda', keep English slugs and copy '4K/private' claims. Our edge is query-order Indonesian slugs, plain natural copy and honesty.

## Glossary

### voice

- **address**: Use 'kamu' (lowercase), consistently; never mix it with 'Anda'. Prefer the imperative with no pronoun ('Tempel link…', 'Simpan ke galeri'), as the existing i18n strings do, so the pronoun is rarely needed. Why 'kamu': the audience is young and mobile (autocomplete is full of 'pp aesthetic', 'gimana cara…', 'cara nge save…'), Indonesian consumer brands such as Telkomsel's how-tos use 'kamu', and every competitor's stiff 'Anda' is part of why they read as machine-translated. Fallback: if the team wants Pinterest's own register, use 'Anda' everywhere. Either works, as long as it's consistent.
- **case**: Title tags and headings follow PUEBI title case: capitalize every word except short function words (di, ke, dari, dan, yang, untuk, tanpa, atau) unless they come first or right after a dash. Example: 'Cara Menyimpan Video Pinterest ke Galeri HP tanpa Aplikasi'. The display H1 is uppercase anyway.
- **free**: gratis (never 'cuma-cuma'). 'free' appears only inside English completions.
- **noLogin**: tanpa login (top completion); 'tanpa akun', 'tanpa daftar' for variety.
- **noApp**: tanpa aplikasi (top completion: 'download video pinterest tanpa aplikasi', 'ke galeri tanpa aplikasi'); 'tanpa install aplikasi' on device pages.
- **noWatermark**: tanpa watermark (dominant; 'tanpa tanda air' and 'tanpa wm' exist but are rare). In descriptions write 'tanpa watermark tambahan' (we add none; creator watermarks stay).
- **quality**: HD, Full HD 1080p, 'ukuran asli' (original size), 'resolusi asli'. 'pecah' = pixelated/blurry, the word users use ('agar tidak pecah'). Never '4K' as a promise.
- **phone**: HP (everyday word for a phone: 'di hp', 'ke galeri hp'). 'ponsel' only in formal body text, at most once. Laptop, PC, komputer, MacBook as is.

### verbs

- **download**: download: titles, H1s and slugs. Inflect the Indonesian way: 'didownload' (passive, attached), 'mendownload' (sparingly). In body copy and buttons use 'unduh' / 'mengunduh' / 'diunduh' (standard Indonesian, matches Pinterest's 'Unduh gambar' and the existing i18n button 'Unduh MP4').

- **saveColloquial**: 'save' (as in 'cara save video pinterest') appears in queries. Use it only as a keyword, never in UI.
- **paste**: tempel (UI); 'paste' only in a parenthetical once
- **copy**: salin ('Salin tautan', as in the app); 'copy link' in body copy once for searchers ('cara copy link pinterest')

- **extract**: ambil / proses (not 'ekstrak', and not 'mengekstrak' as in the current i18n processingText 'Mengekstrak media HD…'; suggest 'Mengambil file HD…')

## hreflang

Use the language-only code 'id' (ISO 639-1 Indonesian) on <html lang> and in hreflang. Indonesia is the only market, and no regional variant (id-ID) would carry different copy, prices or law. Never use the deprecated code 'in' (legacy Java/Android) or invalid forms like pinterestdownloader.io's 'id-05'. Malaysian Malay is a different language ('ms'). A few Malaysian phrasings show up even with gl=id ('cara nak save video dari pinterest'), but they don't justify an ms page. Each id page lists itself ('id'), its English twin ('en') and x-default (English). Skipped pages get no id alternate.

URL pattern: /id/<indonesian-slug>; the homepage is /id (no trailing slash, per normalizeCanonical in src/lib/urls.ts). Lowercase ASCII, hyphens, in the same word order as the winning query ('download-video-pinterest', not 'pinterest-video-download'). Indonesian needs no transliteration. BaseLayout hard-codes the breadcrumb root as name 'Home' at '/'. For id pages it should be 'Beranda' at /id.

## Formats (id-ID)

- **intlLocale**: id-ID
- **decimal**: comma: 4,2 MB; 0,5 detik
- **thousands**: period from 4 digits in prose (1.200 Pin, 12.500); none in technical values (1080p, 600 × 600 px, 2026)
- **units**: space between number and unit: 4,2 MB, 1200 px, 30 detik; none in 720p/1080p. Formats in caps: MP4, JPG, PNG, GIF, ZIP, MP3
- **dimensions**: 600 × 600 px (multiplication sign)
- **dateLong**: 15 Oktober 2026 (Intl.DateTimeFormat('id-ID', {dateStyle: 'long'})); months: Januari Februari Maret April Mei Juni Juli Agustus September Oktober November Desember
- **dateShort**: 15/10/2026 (day/month/year)
- **time**: 24-hour clock with a period: 14.30 (Intl id-ID output); avoid naming time zones (Indonesia has three: WIB/WITA/WIT)
- **percent**: 50% (no space)
- **ordinal**: ke-2, ke-3 (hyphen); 'pertama' for first
- **currency**: Only if ever needed: Rp0 / Rp15.000. Prefer the word 'gratis'.
- **quotes**: “…” and ‘…’ (same as English); quote UI labels in bold or “…”: “Salin tautan”, “Unduh gambar”
- **dash**: Title separator: the em dash with spaces ' — ', not the en dash. BaseLayout.astro builds the breadcrumb name with title.split('—')[0], so an en dash would put the whole title into the breadcrumb.
- **readTime**: '5 menit baca'; word count 'kata'
- **lists**: 'A, B, dan C' (no Oxford-comma rule; the comma before 'dan' is optional, so be consistent)

## Typography

- **glyphCoverage**: Checked with fontkitten against public/fonts/big-shoulders-display-latin-{800,900}-normal.woff2: every A–Z, a–z and 0–9 glyph is present (Indonesian needs no diacritics), and so are — – “ ” ‘ ’ · × … › » ‹ «. Missing: → (U+2192). The current stamps ('Board → ZIP', 'Profile → Avatar') already fall back to Arial Narrow for that arrow in English. For id stamps use '›' ('Papan › ZIP') or add → to the subset.
- **lengthExpansion**: Indonesian body copy runs about 15–30% longer than English (affixes, function words), but the H1s stay compact because they follow the query ('Download Video Pinterest' is as long as 'Pinterest Video Downloader'). Widths below are measured from glyph advances at 900 weight and 46px (phone): DOWNLOADER 234px, MENYIMPAN 213px, DOWNLOAD 193px, PINTEREST 177px. All fit the 343px phone column. Tool H1s set in 2 lines; 'Pinterest ke MP4' in 1; the guides and the Chrome page in 3 (see pages[].h1Fit). Keep the 3-line pages' ledes to one sentence so the ticket stays in the first viewport.
- **widows**: The 3-line H1s end on a short word ('… KE / GALERI', '… DI / LAPTOP', '… DI / HP', '… DI / CHROME'). Bind the preposition to the next word with a non-breaking space (di&nbsp;HP, ke&nbsp;Galeri, di&nbsp;Laptop, di&nbsp;Chrome) so 'DI'/'KE' never end a line and 'HP' never sits alone.
- **breaking**: Indonesian has no long compounds, so H1s need no soft hyphens. Use hyphens:manual in body text: browser hyphenation dictionaries for Indonesian are patchy. Keep 'pin.it', 'MP4' and '1080p' unbroken (nowrap on inline format chips).
- **uppercase**: text-transform:uppercase is safe: Indonesian has no special case mapping (unlike Turkish i/İ). Still set lang="id" on <html> for screen readers.
- **labels**: Gothic label (14px, 0.08em tracking, weight 900): 'TIKET · TAUTAN PUBLIK' measures 138px against 153px for 'ADMIT ONE · PUBLIC LINK', so it fits. The 'BATAL' stamp is 103px against 79px for 'VOID' at 46px, about 30% wider, so check it in the stamp box at its real size.
- **buttons**: Stub button 'Unduh MP4' (9 characters, 204px at 46px/900) is as long as the English one. Avoid 'Download Sekarang' (17 characters) in the stub.
